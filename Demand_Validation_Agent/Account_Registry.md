# Account Registry — Template

Реестр аккаунтов в соцсетях, используемых системой. Обязательное разделение согласно принципу, принятому пользователем: тестовые ("экспериментальные") аккаунты отделены от продающего/брендового аккаунта.

Ни один аккаунт не должен создаваться автоматически массово ("bot farm") — это прямо запрещено ToS TikTok/Instagram (см. Demand_Validation_Agent/README.md). Каждый аккаунт создаётся вручную человеком и авторизуется через официальный OAuth/API платформы.

---

# Типы аккаунтов

## EXPERIMENTAL (тестовый)

Назначение: проверка спроса (Demand Validation), одноразовые/малочисленные тесты.

Риск бана/санкций платформы должен быть изолирован здесь, не должен затрагивать BRAND-аккаунт.

## BRAND (продающий)

Назначение: реальные продажи после подтверждения спроса. Растит собственную репутацию и подписчиков, не используется для рискованных экспериментов.

---

# Формат записи

## Account ID

Уникальный идентификатор в системе (например: TEST_TIKTOK_01, BRAND_TIKTOK_01).

## Platform

TikTok / Instagram / другое.

## Account Type

EXPERIMENTAL / BRAND.

## Handle / Username

Публичное имя аккаунта.

## Created At

Дата создания.

## Authorization Status

- NOT_AUTHORIZED — создан, но не подключён через API;
- AUTHORIZED — подключён через официальный OAuth, API-доступ работает;
- REVOKED — доступ отозван/аккаунт заблокирован.

## API Connection

Ссылка/статус подключения к TikTok Content Posting API или Instagram Professional Account API.

## Linked Experiments

Список experiment_id (см. DemandExperiment_Schema.md), опубликованных через этот аккаунт.

## Notes

Свободные заметки (например, причина бана, если применимо).
