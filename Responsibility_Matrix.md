# Responsibility Matrix — Business Manager vs AI Command Center

Формализовано в Phase 8 на основании факта, зафиксированного в Phase 7: ранее решение о запуске товара могло приниматься в обход Business Manager. Это исправлено; данная матрица фиксирует финальное разделение.

---

# Business Manager

Owner: бизнес-решения.

Ответственность:

- получение агрегированных данных от Product Hunter, Supplier Sourcing Agent, Financial Evaluation, Marketing Agent, (Demand Validation)
- оценка перспективности направления в целом
- принятие одного из трёх решений: запустить / доисследовать / отказаться
- расстановка приоритетов между несколькими товарами-кандидатами

НЕ входит в ответственность Business Manager:

- координация технического выполнения между агентами (это Command Center)
- сохранение данных в Knowledge Base (это Command Center)
- прямое взаимодействие с внешними API/сервисами

---

# AI Command Center

Owner: системная оркестрация.

Ответственность:

- маршрутизация задач между агентами согласно Workflow v1.0
- контроль последовательности этапов (Этап 1 → Этап 9)
- валидация, что каждый этап получил необходимые входные данные, прежде чем передать управление следующему
- сохранение финального результата в Knowledge Base
- обработка сбоев (что делать, если агент не может завершить этап)

НЕ входит в ответственность Command Center:

- принятие бизнес-решений (запуск/отказ) — это исключительно Business Manager
- финансовая или маркетинговая оценка

---

# Однозначность

Каждая критическая ответственность имеет ровно одного владельца:

| Ответственность | Владелец |
|---|---|
| Решение о запуске товара | Business Manager |
| Маршрутизация между агентами | AI Command Center |
| Сохранение в Knowledge Base | AI Command Center |
| Приоритизация нескольких кандидатов | Business Manager |
| Обработка сбоев workflow | AI Command Center |

0 критических ответственностей с двумя владельцами.
