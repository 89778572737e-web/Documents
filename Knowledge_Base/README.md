# Knowledge Base

## Назначение

Knowledge Base — это централизованное хранилище знаний AI-системы.

Здесь сохраняется информация, необходимая для анализа товаров, поставщиков, рынка и принятия бизнес-решений.

---

# Роль в системе

Knowledge Base используется всеми AI-агентами:

- Product Hunter сохраняет результаты поиска товаров.
- Business Manager использует данные для стратегического анализа.
- Marketing Agent получает информацию для создания маркетинговых решений.
- Sales Agent использует данные для подготовки продаж.

---

# Основные разделы

## Products

База потенциальных и подготовленных товаров.

Содержит:

- описание товара;
- категорию;
- анализ рынка;
- преимущества;
- недостатки;
- оценку перспективности.

---

## Suppliers

База поставщиков.

Содержит:

- название компании;
- платформу;
- категорию товара;
- условия сотрудничества;
- качество;
- оценки.

---

# Правила работы

Все записи должны:

- иметь понятную структуру;
- содержать проверенную информацию;
- обновляться при появлении новых данных;
- использовать единый формат.

---

# Главный принцип

Knowledge Base является общей памятью системы.

Все важные решения и результаты анализа должны сохраняться здесь для дальнейшего использования AI-агентами.
