# Products Database

## Назначение

Products Database — единая база товаров и бизнес-возможностей AI-системы.

Здесь хранятся только данные о товарах и результаты работы AI-агентов.

Инструкции агентов хранятся в отдельных файлах и не дублируются в этой базе.

---

# Database Rules

Каждый товар в базе должен:

- иметь уникальный Product ID;
- иметь описание;
- иметь результаты необходимых этапов анализа;
- содержать выявленные риски;
- иметь связь с поставщиком;
- иметь текущий статус;
- иметь следующий шаг.

Неизвестные данные обозначаются как:

Требует проверки.

Запрещено придумывать отсутствующие фактические данные.

# Statuses

## Product

- Исследуется
- Прошел анализ
- Готов к тестированию
- Запущен
- Отклонён

## Supplier

- Найден
- Проверяется
- Одобрен
- Тестируется
- Отклонён

---

# Principle

Products Database является единым источником структурированных данных о товарах для AI-системы.

Инструкции AI-агентов не хранятся в Products.md.

Все новые данные добавляются после соответствующего анализа и проверки.
