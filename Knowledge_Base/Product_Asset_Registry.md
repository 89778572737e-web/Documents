# Product Asset Registry — Template

Реестр прав на фото/видео материалы, используемые для товаров. Обязателен для Compliance Gate (см. Demand_Validation_Agent/README.md) — без этого раздела публикация контента не допускается.

Юридический принцип (обсуждён и согласован с пользователем): важно не "не спалиться", а реально иметь право использовать материал. Фото с чужих маркетплейсов/листингов без разрешения — нарушение авторских прав независимо от вероятности последствий.

---

# Формат записи

## Asset ID

Уникальный идентификатор материала.

## Product ID

Ссылка на товар, к которому относится материал.

## Source Type

Один из вариантов:

- SUPPLIER_PROVIDED — предоставлено поставщиком с явным разрешением на использование в рекламе;
- AI_GENERATED — сгенерировано AI с нуля, без использования чужого исходного фото;
- OWN_PHOTO — собственное фото/видео (например, закупленного образца);
- LICENSED — приобретена лицензия на стоковый материал.

ЗАПРЕЩЁННЫЕ источники (не для использования): фото с чужих листингов маркетплейсов (Amazon, eBay и т.д.) без прямого разрешения; фото конкурентов; чужой пользовательский контент без разрешения.

## Source URL

Ссылка на источник (если применимо).

## Rights Status

- VERIFIED — право на использование подтверждено (например, письменное разрешение поставщика);
- PENDING — запрошено, ответ не получен;
- NOT_VERIFIED — использовать нельзя, пока не подтверждено.

## License / Permission Reference

Ссылка на документ/переписку, подтверждающую право использования (если применимо).

## Allowed Commercial Use

Да / Нет / Требует уточнения.

## Allowed Derivatives

Разрешено ли создавать производные материалы (например, AI-видео на основе этого фото)? Да / Нет / Требует уточнения.

---

# Правило системы

Ни один материал не может использоваться в Demand Validation или маркетинге, пока Rights Status не установлен в VERIFIED.

Это отдельная, обязательная проверка внутри Compliance Gate (см. Demand_Validation_Agent/README.md).
